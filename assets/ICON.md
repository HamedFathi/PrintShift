# PrintShift icon

The application icon combines a screenshot capture frame with a keyboard keycap. The navy, white, and teal design is shared by the executable, window, and notification icon. The disabled notification icon is converted to grayscale at runtime without changing the source artwork.

Files:

- `printshift-icon.png`: original transparent RGBA artwork.
- `../app.ico`: Windows multi-resolution container, with 16, 24, 32, 48, 64, 128, and 256 pixel images.

The artwork was created with built-in image generation. The PNG was converted to ICO for Windows packaging; the original artwork was retained.

Generation prompt:

> A single polished Windows desktop application icon for PrintShift, a utility that replaces a missing Print Screen keyboard key. A compact rounded navy keycap with a restrained teal accent and a bold white screenshot capture frame around a centered keyboard-key symbol. Minimal vector-like geometry, thick consistent strokes, generous spacing, legible at small sizes. Transparent background. No text, watermark, platform logo, scene, or additional icons.
